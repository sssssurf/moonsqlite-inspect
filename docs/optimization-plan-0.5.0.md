# MoonSQLite Inspect 0.5.0 优化规划书

2026 年 11 月 23 日制定。实施基线为已发布的 `0.4.1`，仓库基线为 `f9de7b5`。本轮目标是让使用者在已捕获的 WAL 历史中，快速定位指定记录，并能分批浏览超过单份 JSON 容量的表。交付物包括 MoonBit 接口、命令行、SQLite 对照、前后对比数据和可执行验收示例。 [现有包](https://mooncakes.io/docs/sssssurf/moonsqlite-inspect) · [官网验收要求](https://moonbitlang.github.io/Hackathon2026/#entry-rules)

## 现状与用户场景

历史读取已经支持按提交重建、完整表扫描、行级差异和单元来源。现有 `wal-rows` 依次处理全表，结果超过 8 MiB 时返回错误。用户若只关心一个订单或状态行，仍需生成整表结果再筛选。`row` 和 `range` 的分支定位能力目前用于备份和最新快照。

1. **追查已知记录。** 给定提交编号和 `rowid=41`，直接查看该次提交中的状态和值的来源。目标行在当时尚未插入或已删除时返回空结果。
2. **核对历史大表。** 给定提交和行号范围，按每批行数与输出字节数分页。继续使用返回的首个未导出行号，涵盖稀疏、负数和 64 位边界键。
3. **验证采集与出处。** 对相同的离线采集应用清单校验，使用返回的页号和偏移定位基线或 WAL 帧。沿用同一 WAL 周期基线、普通 rowid 表和原始存储值的语义。

## 实施顺序与通过条件

| 阶段 | 工作与交付 | 通过条件 |
| --- | --- | --- |
| 1. 建立对照 | 从 `0.4.1` 保留可执行版本。准备 SQLite 生成的多页采集，记录 SQL 查询及原始帧结果。 | 旧版全表输出可作为点查对照，尺寸、数据和重复次数可复现。 |
| 2. MoonBit 历史定位 | 复用普通表已有的 rowid 范围游标，从历史页索引按需取页。暴露 `WalRevision::find_row` 和 `WalRevision::visit_rowid_range`，结果附单元来源。 | 只遍历与区间相交的分支。SQLite 对照核验最小、最大及稀疏 rowid、历史插入和删除、主文件/WAL 来源、跨页和溢出值。 |
| 3. 命令行与续传 | 增加 `wal-row` 和 `wal-range`，支持 `--manifest`。`wal-range` 在行数或 8 MiB 限额到达时返回首个未输出行号 `next_rowid`。单行超限时返回明确错误。 | 连续分页覆盖全部目标行且顺序一致。字节预算按 UTF-8 计算并包含换行。解析、校验和读取错误时标准输出为空。原有命令与选项通过回归。 |
| 4. 验证与对比 | 新场景纳入 SQLite 对照与独立包测试。基准采用同一份采集、同一行，检查新旧值和来源一致后比较多次耗时与峰值内存。 | 四个后端检查、构建和测试通过。SQLite 对照覆盖续传、清单错配和结果来源。记录实测环境与结论。 |
| 5. 完成交付 | 更新 README、设计说明、变更日志、验收对照和现有申报书。先验证公开仓库，再发布 Mooncakes 并在独立工程重装。 | README 新命令由干净分发包执行并核对输出。公开仓库收录实现与证据，发布包与注册表一致，公开包通过四个后端的消费测试。 |

## 设计和测试要点

- 历史视图继续使用 MoonSQLiteFile 校验 WAL、读取目录及执行顺序扫描。从既有的范围游标提取共用页读取接口，历史视图按已选提交供页，复用 B-tree 键与单元检查。范围定位验证实际访问的路径，完整扫描可用于检查整张表。 [SQLite B-tree 格式](https://sqlite.org/fileformat2.html#b_tree_pages) · [MoonSQLiteFile 0.8.1](https://mooncakes.io/docs/prowk/moonsqlitefile)
- 续传使用第一个未接收的真实行号，下一次将其作为闭区间的起点。整个过程使用同一个采集、提交、表和终止行号。库回调返回 `false` 时保留当前行供重试。
- 分别用 SQLite 的 `WHERE rowid=?` 和 `WHERE rowid BETWEEN ? AND ? ORDER BY rowid` 获取期望结果。使用原始 WAL 帧检查来源，构造累计超过限额和单行超限的场景。性能对比另外运行，耗时不作为 CI 门槛。
- 发布前以线上运行记录核对格式、四后端、SQLite、干净示例与独立分发包。将已验证的内容写入项目材料，附运行链接、版本和可复现命令。

## 验收演示

用 README 的示例采集先校验清单。在修订 1 中定位 `rowid=41`，应看到 `waiting` 和 WAL 页来源。比较修订 0 与修订 2，净差异为空。从修订 3 取跨越 64 位边界的历史键范围，使用小批次数与 `next_rowid` 续传。演示说明分别指出历史版本、实际单元位置与分页游标。
